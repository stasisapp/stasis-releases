# Stasis releases

Installers for [Stasis](https://trystasis.app), the notes app that keeps your pages as plain Markdown files.

Download the newest `Stasis-Setup-x.y.z.exe` from [Releases](https://github.com/stasisapp/stasis-releases/releases/latest). Once installed, Stasis keeps itself up to date from here.

This repository holds only the installers. It has no source code.
